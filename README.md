# YouTube Clone 

Bu proje, YouTube’un temel işlevlerini yeniden üreten ve kullanıcı dostu bir deneyim sunmayı amaçlayan bir video içerik platformu klonudur. Modern web geliştirme yaklaşımlarıyla inşa edilen bu uygulama, bileşen bazlı mimarisi, hızlı sayfa geçişleri ve duyarlı tasarımıyla hem masaüstü hem mobil cihazlarda sorunsuz çalışacak şekilde optimize edilmiştir.



##  Projenin Amacı

YouTube Clone, **frontend geliştirme yeteneklerini pekiştirmek**, **modern UI/UX prensiplerini uygulamak** ve **popüler JavaScript kütüphaneleriyle gerçek dünya uygulaması geliştirmek** amacıyla oluşturulmuştur.

Bu projede hedeflenen başlıca kazanımlar:

- REST API kullanımı ve asenkron veri çekme
- Dinamik routing ve sayfa geçişleri
- Responsive ve sezgisel arayüz tasarımı
- Gerçek dünya projelerinde kullanılan açık kaynak kütüphanelerin entegrasyonu


##  Proje Mimarisi ve Özellikler

- ✅ **Video arama ve kategori filtreleme** (YouTube API üzerinden)
- ✅ **Responsive tasarım** (Tailwind CSS ile mobil uyumlu yapı)
- ✅ **Gerçek zamanlı video oynatımı** (react-player kullanılarak)
- ✅ **Sayfa bazlı yönlendirme sistemi** (react-router-dom)
- ✅ **İzlenme, beğeni vb. sayıları okunabilir formatta gösterme** (millify)
- ✅ **İkon kütüphanesi ile zengin görsel deneyim** (react-icons)
- ✅ **Temiz, modüler ve yeniden kullanılabilir bileşen yapısı**


##  Kullanılan Teknolojiler

- **React** : Bileşen tabanlı kullanıcı arayüzü oluşturmak için
- **axios** : YouTube API ile HTTP istekleri yapmak için
- **react-router-dom** : Çok sayfalı yapı ve yönlendirme sistemi
- **react-player** : YouTube videolarını yerleştirmek ve oynatmak için
- **millify** : Büyük sayıları (1.2K, 3.4M gibi) kısaltmak için
- **react-icons** : Modern ve özelleştirilebilir ikon desteği
- **Tailwind CSS** : Utility-first sınıflar ile hızlı ve etkili stil uygulamaları
